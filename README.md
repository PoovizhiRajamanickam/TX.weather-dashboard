Weather Dashboard Application

A responsive real-time weather tracking web application built using HTML5, CSS3, and asynchronous JavaScript to fetch live meteorological data from public REST APIs.

Features

* Real-Time Weather Data: Fetches live temperature, humidity, and wind speed for any location worldwide using the Open-Meteo API.
* Robust Global Geocoding: Advanced search functionality that accurately finds global cities, states, and districts with smart fallback handling.
* Modern User Interface: Styled with sleek glassmorphism effects, responsive card layouts, and intuitive error handling.

Tech Stack

* Markup: HTML5
* Styling: CSS3 with custom gradients and flexbox architecture
* Logic: Vanilla JavaScript (ES6) with async/await and Fetch API
* Tools: Git, GitHub, Visual Studio Code

File Structure

* index.html: Application structure and search input layout
* style.css: Modern visual styling and responsive UI rules
* script.js: Asynchronous API calls, geocoding handling, and DOM updates
